# @tiaforge-ui/create

```sh
npm create @tiaforge-ui my-app
```

Creates a small task board built with [sinter](https://github.com/tiaforge/sinter) (your JSON API
bound to plain HTML) and [temper](https://github.com/tiaforge/temper) (CSS for semantic HTML), with
a demo API that runs inside Vite. It shows server data with live updates across tabs, optimistic
changes that roll back, a dialog without JavaScript, an island (a canvas chart), next-page data and
page transitions, and build-time checks that turn typos into build errors.

The template is in [`template/`](template). Its README lists what to try first.
